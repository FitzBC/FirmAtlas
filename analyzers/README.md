# 分析器接入

分析器是不可信输入与平台控制面之间的适配器。每个分析器只需接受一个由摘要标识的制品和受限运行参数，并返回 `AnalysisReport`；不直接写平台数据库。

首批计划分析器：

- `identify`：文件类型、架构、端序、签名和加密迹象；
- `unpack`：分区、容器、压缩层和文件系统；
- `inventory`：包、库、内核、模块及版本证据；
- `startup`：init、systemd、BusyBox、启动脚本和执行主体；
- `communications`：端点、协议、IPC 与通信关系；
- `interfaces`：Web、RPC、CLI、消息和设备接口及参数；
- `secrets`：证书、密钥和凭据线索，输出默认脱敏；
- `binary`：符号、字符串、导入、调用和补丁特征。

分析器必须固定工具及规则版本、声明资源预算、区分“不支持/失败/未发现”，并为每个观察事实提供证据定位。
