## 1. 本轮出口

本轮没有新增一个只转发调用的浅 Module，而是在两个既有深 Module 的
Interface 后扩展确定性语法：

```text
discover_web_configuration(SourceArtifactEntry, bytes) -> WebConfigProducerResult
discover_script_backend(SourceArtifactEntry, bytes) -> ScriptBackendProducerResult
assemble_discovery_catalog(DiscoveryCatalogInput) -> DiscoveryCatalog
```

- Web Configuration Producer `0.2.0` 新增
  `proprietary_httpd`，静态解析 `Control/Alias/Location/External`；
- Script Backend Producer `0.2.0` 新增 PHP-XGI
  `ACTION_POST/query/queryEnc/set/setEnc`；
- Discovery Catalog 新增 `source_inventory_coverage_status`，防止“选中文件分析
  completed”掩盖“整机 Inventory partial”；
- Corpus 聚合中，真实固件 coverage gap 不再被同类别 contract fixture 掩盖。

所有结果仍通过 EvidenceAtom、稳定 ID、Producer 版本和 Coverage Ledger
发布；没有执行固件 PHP，也没有输入 CVE、PoC 或目标接口 seed。

## 2. TDD 驱动的语义边界

本轮 RED → GREEN 冻结了四个关键行为：

1. `/HNAP1` 的 Alias、Location 和 External 必须分别保留，不能压成路径标签；
2. PHP heredoc/动态输出中的伪配置不能被当成静态 httpd 配置；
3. `ACTION_POST == literal` 才能发布 operation selector，普通变量不会自动
   冒充 HTTP 参数；
4. 上游 Inventory 非 completed 时，即使所有选定 Producer completed，Catalog
   最高仍为 partial。

Producer 只在声明的 dialect 上启用：PHP-XGI 状态树扫描要求文件中存在
`$ACTION_POST`，从而避免把一般 PHP 项目中同名 `query()` 函数当成固件 XGI。
`set()` 的第二参数只有在是简单变量时才记录 parameter alias；复杂表达式仍
保留写操作和状态路径，但不发明输入身份。

### 3.2 PHP-XGI

| 文件 | Selector | 状态访问 | EvidenceAtom |
| --- | ---: | ---: | ---: |
| `www/home_sys.php` | 0 | 28 | 28 |
| `www/__action.php` | 5 | 238 | 248 |

`__action.php` 恢复的 selector 为 `__sample`、`tool_admin`、`tool_sntp`、
`sys_setting`、`st_logs`；状态访问合计 106 次 `query`、2 次
`query_encrypted`、128 次 `set` 和 2 次 `set_encrypted`。

因此当前可解释架构为：

```text
HNAP request -> proprietary httpd External -> /usr/sbin/hnap
page POST -> ACTION_POST dispatcher -> __action.php -> XGI state tree
```

这是一个混合控制面，而不是把所有 D-Link 页面都归入 HNAP。

## 5. 反思与下一轮

本轮暴露的关键问题不是 HNAP 解析能力，而是 coverage 的纵向传播：若 Catalog
只观察 Producer Batch，会产生“局部成功抬高整机成功”的系统性误报。把源
Inventory coverage 加入 Catalog Interface 后，这个规则由所有调用者共同复用，
也进入 catalog identity，而不是靠报告脚本打补丁。

M1-13 已完成固件 chroot 绝对 symlink 的安全解析：解析目标始终限制在
Inventory root 内，记录原始 link 与规范目标，循环、普通缺失目标、深度耗尽和
真正越界继续 partial。下一步摄取共享 CGI、脚本后端原始制品和 Native-only
原始样本。
